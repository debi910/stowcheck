How it works

AI reads. Code decides. People get the unsure cases.

01

Read the cargo

"Pool chlorine tablets" is calcium hypochlorite. The AI writes search terms, then must pick a real row of the official table or say it isn't sure.

02

Every pair goes through the 176.83 segregation table and the 176.84 stowage codes. Same input, same answer, rule cited.
