How it works

AI does the reading. Code does the rules. Humans get the unsure cases.

AI reads the cargo

"Pool chlorine tablets" becomes calcium hypochlorite. The AI can only pick real rows from the official table, never invent one.

Code applies 49 CFR

Every pair is checked against the segregation table and the chemical-family rules. Same input, same answer, with the rule cited.

Unsure goes to a human

Vague lines like "assorted chemicals" are flagged, and the check is marked incomplete instead of pretending it's safe.

Measured, not claimed

Same free model (Gemma 4) on both sides. Data and scripts are in the repo.
